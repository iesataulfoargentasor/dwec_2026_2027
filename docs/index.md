# Desarrollo Web en Entorno Cliente

Apuntes del módulo **DWEC** (CFGS Desarrollo de Aplicaciones Web) del IES Ataúlfo Argenta.

Este sitio reúne el material de teoría actualizado para que puedas consultarlo desde cualquier dispositivo, con búsqueda, modo oscuro y ejemplos de código listos para copiar.

Las **entregas evaluables** y los cuestionarios siguen en el aula Moodle.

## Cómo navegar

- Usa el **menú lateral** para saltar entre apartados.
- La **tabla de contenidos** de la derecha recorre los epígrafes de cada página.
- La **búsqueda** del encabezado localiza un concepto concreto (`const`, `===`, `for...of`…).
- Cada bloque de código tiene un botón para **copiar**.

!!! tip "Consola del navegador"
    Durante esta unidad trabajarás mucho con la consola: en Chrome, Edge o Firefox pulsa :kbd:`F12` o :kbd:`Ctrl` + :kbd:`Mayús` + :kbd:`J`.
