No se ejecuta el caso al cargar: en ese momento normalmente estarías arriba y no se apreciaría movimiento. El enlace baja mediante un ancla HTML, sin JavaScript.

01

La pantalla muestra solo una parte

El documento es más alto que el área visible. window.innerHeight indica la altura de esa área, no la altura de todo este HTML.

Desplázate y ejecuta window.scrollY en consola: informa de cuántos píxeles CSS has bajado desde el principio.

02

Posición de destino

window.scrollTo({ top: 0, behavior: "smooth" }) solicita volver a la posición vertical cero.

top: 0 indica el destino; behavior: "smooth", que el recorrido se anime. El navegador decide su duración.

Como no se indica left, la posición horizontal se conserva. Esta página está diseñada para practicar el desplazamiento vertical.

03

La posición inicial se guarda antes

El caso resuelto guarda scrollX y scrollY antes de solicitar el movimiento. Por eso el resumen conserva el lugar desde el que comenzaste.

La animación no detiene JavaScript. Leer scrollY inmediatamente después de llamar al método no garantiza que el recorrido haya terminado.

Inicia la sesión desde aquí

Ya estás lejos del comienzo del documento. Deja la consola abierta y ejecuta en ella el bloque mostrado.

Selecciona y copia el código completo, incluidas las llaves exteriores. Es un bloque de instrucciones, no una función.

Resultado esperado: al aceptar los diálogos y cerrar el último aviso, la página vuelve suavemente al inicio. En consola queda el desplazamiento inicial, normalmente con Y mayor que cero.

Cancelar el nombre, escribir solo espacios o rechazar el inicio no debe mover la página mediante el script. El navegador puede ajustar la vista al enfocar controles o abrir herramientas.

Para repetir, vuelve a bajar mediante el enlace del inicio. No hace falta recargar.

const nombreBruto = prompt("¿Cómo te llamas?", "");

Cómo aplicar tu propio script

Esta página no registra eventos ni ejecuta el caso automáticamente. El enlace de navegación es HTML y el ejemplo usa instrucciones secuenciales.

Puedes sustituir el bloque mostrado por tu propio script secuencial y ejecutarlo desde la consola después de bajar.

También puedes ejecutar el ejemplo directamente en consola, después de bajar, sin funciones propias ni eventos. Si lo enlazas como un script que se ejecuta al cargar, el movimiento puede no apreciarse porque la página ya estará al principio.
