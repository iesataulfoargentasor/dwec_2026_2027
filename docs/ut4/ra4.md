# Resultado de aprendizaje 4 (RA4)

Esta unidad de trabajo desarrolla el **RA4** del módulo *Desarrollo Web en Entorno Cliente*.

## Enunciado

**RA 4:** Programa código para clientes web analizando y utilizando estructuras definidas por el usuario.

## Criterios de evaluación

| CE | Criterio | Dónde se trabaja en la UT4 |
| --- | --- | --- |
| **a)** | Se han clasificado y utilizado las funciones predefinidas del lenguaje. | [4.1 Funciones predefinidas](funciones-predefinidas.md) |
| **b)** | Se han creado y utilizado funciones definidas por el usuario. | [4.2 Funciones de usuario](funciones-usuario.md) |
| **c)** | Se han reconocido las características del lenguaje relativas a la creación y uso de matrices (arrays). | [4.3 Arrays](arrays.md) |
| **d)** | Se han creado y utilizado matrices (arrays). | [4.3 Arrays](arrays.md) |
| **e)** | Se han utilizado operaciones agregadas para el manejo de información almacenada en colecciones. | [4.4 Operaciones agregadas](operaciones-agregadas.md) |
| **f)** | Se han reconocido las características de orientación a objetos del lenguaje. | [4.5 Orientación a objetos](orientacion-objetos.md) |
| **g)** | Se ha creado código para definir la estructura de objetos. | [4.6 Objetos de usuario](objetos-usuario.md) |
| **h)** | Se han creado métodos y propiedades. | [4.6 Objetos de usuario](objetos-usuario.md) |
| **i)** | Se ha creado código que haga uso de objetos definidos por el usuario. | [4.6 Objetos de usuario](objetos-usuario.md) |
| **j)** | Se han utilizado patrones de diseño de software. | [4.7 Patrones de diseño](patrones.md) |
| **k)** | Se ha depurado y documentado el código. | Comentarios, JSDoc, `console` y DevTools en todos los apartados |

!!! note "Cómo se evalúa"
    En las prácticas se pide **definir** funciones y objetos, **manejar** arrays (incluido `map`/`filter`/`reduce`) y **usar** un patrón sencillo. Ejecuta en el navegador y comprueba el resultado. Las entregas formales siguen en Moodle.
