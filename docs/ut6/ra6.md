# Resultado de aprendizaje 6 (RA6)

Esta unidad de trabajo desarrolla el **RA6** del módulo *Desarrollo Web en Entorno Cliente*.

## Enunciado

**RA 6:** Desarrolla aplicaciones web analizando y aplicando las características del modelo de objetos del documento.

## Criterios de evaluación

| CE | Criterio | Dónde se trabaja en la UT6 |
| --- | --- | --- |
| **a)** | Se ha reconocido el modelo de objetos del documento de una página web. | [6.1 El modelo DOM](modelo-dom.md) |
| **b)** | Se han identificado los objetos del modelo, sus propiedades y métodos. | [6.2 Objetos, propiedades y métodos](objetos-propiedades.md) |
| **c)** | Se ha creado y verificado un código que acceda a la estructura del documento. | [6.3 Acceso al documento](acceso-documento.md) |
| **d)** | Se han creado nuevos elementos de la estructura y modificados elementos ya existentes. | [6.4 Crear y modificar elementos](crear-modificar.md) |
| **e)** | Se han asociado acciones a los eventos del modelo. | [6.5 Eventos del modelo](eventos-dom.md) |
| **f)** | Se han identificado las diferencias que presenta el modelo en diferentes navegadores. | [6.6 Diferencias entre navegadores](diferencias-navegadores.md) |
| **g)** | Se han programado aplicaciones web de forma que funcionen en navegadores con diferentes implementaciones del modelo. | [6.7 Compatibilidad](compatibilidad.md) |
| **h)** | Se han independizado las tres capas de implementación (contenido, aspecto y comportamiento), en aplicaciones web. | [6.8 Tres capas](tres-capas.md) |

!!! note "Cómo se evalúa"
    En las prácticas se pide **recorrer** el árbol, **crear o cambiar** nodos, **escuchar** eventos con `addEventListener` y entregar HTML, CSS y JS **en archivos separados** (sin `onclick` ni estilos embebidos en el script). Comprueba el resultado en **más de un navegador**. Las entregas formales siguen en Moodle.
