# Resultado de aprendizaje 5 (RA5)

Esta unidad de trabajo desarrolla el **RA5** del módulo *Desarrollo Web en Entorno Cliente*.

## Enunciado

**RA 5:** Desarrolla aplicaciones web interactivas integrando mecanismos de manejo de eventos.

## Criterios de evaluación

| CE | Criterio | Dónde se trabaja en la UT5 |
| --- | --- | --- |
| **a)** | Se han reconocido las posibilidades del lenguaje de marcas relativas a la captura de los eventos producidos. | [5.1 Modelo de eventos](modelo-eventos.md) (atributos `onclick`, `onsubmit`…) |
| **b)** | Se han identificado las características del lenguaje de programación relativas a la gestión de los eventos. | [5.1 Modelo de eventos](modelo-eventos.md) (`addEventListener`, objeto `event`, burbujeo) |
| **c)** | Se han diferenciado los tipos de eventos que se pueden manejar. | [5.2 Tipos de eventos](tipos-eventos.md) |
| **d)** | Se ha creado un código que capture y utilice eventos. | [5.1](modelo-eventos.md) y [5.2](tipos-eventos.md); ejemplos en [5.4](apariencia-comportamiento.md) y [5.5](validacion.md) |
| **e)** | Se han reconocido las capacidades del lenguaje relativas a la gestión de formularios web. | [5.3 Formularios](formularios.md) y [5.4 Apariencia y comportamiento](apariencia-comportamiento.md) |
| **f)** | Se han validado formularios web utilizando eventos. | [5.5 Validación y envío](validacion.md) |
| **g)** | Se han utilizado expresiones regulares para facilitar los procedimientos de validación. | [5.6 Expresiones regulares](expresiones-regulares.md) |
| **h)** | Se ha probado y documentado el código. | Consola, DevTools y comentarios/JSDoc en todos los apartados |

!!! note "Cómo se evalúa"
    En las prácticas se pide **asociar** manejadores (mejor con `addEventListener`), **distinguir** tipos de evento, **gestionar** un formulario y **validar** datos (HTML5 y/o JavaScript, con al menos un patrón regex). Ejecuta en el navegador, comprueba el resultado y documenta. Las entregas formales siguen en Moodle.
